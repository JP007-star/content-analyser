## Content Guardrails
- ❌ No "Hello World" examples — real code only
- ❌ No "it depends" without explaining *what* it depends on
- ❌ No unversioned claims — always specify Java version
- ❌ No code without explanation of *why*
- ✅ Every claim backed by spec / source / benchmark
- ✅ Version-specific behavior called out (Java 8 vs 11 vs 17 vs 21+)
- ✅ One actionable takeaway per video
- ✅ Production context for every concept
